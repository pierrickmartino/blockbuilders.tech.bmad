## Executive Summary

1. **Next.js remains the top risk.** The pin `16.2.6` predates the July, September, October and 2026-11-03 security releases. The 11-03 release reportedly fixes seven issues (one high, six medium) in 16.4.5. The October release reportedly fixed two critical RCEs (16.4.1). Version numbers come from vendor pages and must be checked against nextjs.org or GitHub advisories. Upgrading needs human approval.
2. **React is above the known-fixed floor.** The pin `19.2.6` is above 19.2.5, which fixed the April 2026 RSC DoS (CVE-2026-23869). Nothing newer was found, but only one search covered this.
3. **PostgreSQL had a large security batch in August 2026** (reportedly 28 CVEs, fixed in 16.15 and its siblings). The compose files use the floating tag `postgres:16-alpine`, so the running version depends on the last image pull. Whether production is on 16.15 or later is unknown.
4. **No advisories were found for SQLModel, Alembic, RQ or Redis.** Searches returned little, which is not evidence that they are clean.
5. **Open issues are unchanged.** The three `ready-for-agent` issues are still blocked on human PostHog setup.
6. **Version numbers across nightly reports conflict.** The search index is inconsistent, so no upgrade target should be picked without a primary-source check.
