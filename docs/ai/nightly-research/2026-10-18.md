## Security Risks

### P0 — Next.js `16.2.6` behind security releases (carried, re-confirmed)
Sources: [Next.js 16.2.6 / 15.5.18 advisories](https://lilting.ch/en/articles/nextjs-security-release-16-2-6-15-5-18), [DEV: July 2026 release](https://dev.to/mr_manushukla/nextjs-july-2026-security-release-9-cves-patched-in-16211-and-15521-3o9b), [achromatic changelog](https://www.achromatic.dev/changelog/july-2026-nextjs-security-release), [pkgpulse](https://www.pkgpulse.com/guides/nextjs-16-security-patches-cve-2026).
- July 2026: nine CVEs (four high, five medium) fixed in `16.2.11`.
- Middleware/proxy auth bypass (CVE-2026-64642 per one source) affects Turbopack apps with a single i18n locale. Whether this repo uses middleware auth or i18n was not checked.
- One undated source claims `16.3.3` / `15.5.24` fixes two critical RCEs (Windows servers, AVIF optimization). Unverified; confirm on nextjs.org and GitHub advisories.
- A bump needs a stated reason and human approval. Verify with `cd frontend && npm test && npm run lint && npm run build`.

### P1 — PostgreSQL May 2026 security release
Sources: [Borncity](https://borncity.com/news/postgresql-schliesst-11-sicherheitsluecken-in-einem-grossen-update/), [AhnLab CVE-2026-6476](https://asec.ahnlab.com/en/93764/), [TuxCare CVE-2026-6478](https://errata.tuxcare.com/els_os/tuxcare9.6esu/CLSA-2026-1779697425.html).
- 11 CVEs fixed across 14–18, including CVE-2026-6472 (CREATE TYPE permission check), CVE-2026-6476 (SQL injection in `pg_createsubscriber`), and CVE-2026-6478 (MD5/SCRAM timing side channel). Sources disagree on severity for CVE-2026-6637; treat as unconfirmed.
- Exposure here is likely low (no logical-replication tooling in use), but the SCRAM timing issue is relevant to any network-reachable database. Confirm the running image is 16.14+ (`docker compose exec db postgres --version`).
- A SUSE advisory dated September 2026 reportedly lists 24 vulnerabilities for postgresql15; I could not verify details.
