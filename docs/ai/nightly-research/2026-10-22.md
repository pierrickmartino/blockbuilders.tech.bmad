## Security Risks

### P0 — Next.js `16.2.6` behind four security releases
Sources: [Next.js 16.2.6 / 15.5.18 advisories](https://lilting.ch/en/articles/nextjs-security-release-16-2-6-15-5-18), [upcoming security release, 2026-09-22 (official)](https://nextjs.org/blog/upcoming-nextjs-security-release-september-22-2026), [July 2026 release](https://www.achromatic.dev/changelog/july-2026-nextjs-security-release), [16.3.3 / 15.5.24 RCE write-up](https://teramont.net/blog/nextjs-16-3-3-15-5-24-critical-rce).
- Sept 22: out-of-band critical fix for an upstream dependency in 16.3.6 / 15.5.26. The official post was an announcement; I did not confirm the advisory details.
- Aug 25 (third-party): two critical RCE issues; Windows deployments and AVIF image processing flagged.
- Jul: four high and five medium CVEs fixed in 16.2.11, including a middleware auth bypass reported for Turbopack apps with a single i18n locale. I did not check whether the repo uses middleware auth or i18n.
- Recommendation: propose a bump to the latest 16.x patch, with the reason above. Verify with `cd frontend && npm test && npm run lint && npm run build`. Do not bump without human approval.

### P1 — React RSC denial of service
Sources: [CVE-2026-23869](https://advisories.gitlab.com/npm/react-server-dom-parcel/CVE-2026-23869/), [CVE-2026-23870](https://advisories.gitlab.com/npm/react-server-dom-webpack/CVE-2026-23870/).
- Fixed in 19.2.5 / 19.2.6. Repo pins 19.2.6, so no action. Keep React packages aligned when Next.js is bumped.

### P1 — PostgreSQL
Sources: [PostgreSQL release summary](https://releasebot.io/updates/postgresql/postgresql), [Debian tracker CVE-2026-14679](https://security-tracker.debian.org/tracker/CVE-2026-14679).
- May release fixed 11 CVEs, including CVE-2026-6478 (MD5 timing channel; not applicable to scram-sha-256 default) and CVE-2026-6638 (SQL injection in logical replication refresh; not relevant unless replication is used).
- Later CVEs (CVE-2026-14676, -14679, -19385) are listed as unfixed in Debian and tied to a newer release. Details unverified.
- Action: check `docker compose exec db postgres --version` and pull the current 16.x image.
