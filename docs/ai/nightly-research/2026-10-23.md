## Security Risks

### P0 — Next.js `16.2.6` behind the 2026-10-14 update
Sources: [Next.js security update, October 14 2026 (official)](https://nextjs.org/blog/nextjs-security-update-october-14-2026), [Singapore CSA alert AL-2026-148](https://www.csa.gov.sg/alerts-and-advisories/alerts/al-2026-148/).
- **GHSA-673q-mjm6-r5xr** (critical): unauthenticated RCE in App Router with Cache Components when a `use cache` function returns multiple typed arrays. No workaround. *Repo: no `use cache` found.*
- **CVE-2026-96889 / GHSA-2464-fhr4-w9xw** (critical): RCE in the Image Optimization API via an upstream library, on glibc-based Linux. Workaround: `sharp` 0.35.5 or later. *Repo: no `sharp` dependency declared and no `images` config; whether `next/image` is used and what libc the frontend image uses were not checked.*
- **GHSA-p3m5-59mp-jv5r** (high): DoS in App Router with at least one Server Action. *Repo: no `"use server"` found.*
- The official post says to upgrade immediately even if the application has no similar code. The CSA alert (2026-10-20) urges immediate patching.
- Recommendation: propose a bump to `next@16.4.1` (or newer 16.x patch) with matching React. This crosses a minor (16.2 to 16.4), so run `cd frontend && npm test && npm run lint && npm run build` and check the 16.3/16.4 release notes for breaking changes. Needs human approval before any change.
- Earlier unaddressed releases (July `16.2.11`, August `16.3.3`, September `16.3.6`) are covered by 16.4.1 but were not re-verified this cycle; see `2026-10-22.md`.
