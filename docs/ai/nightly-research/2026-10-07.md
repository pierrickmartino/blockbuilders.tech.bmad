## Security Risks

### P0 — Next.js `16.2.6`
Sources: [Next.js: upcoming security release, 2026-09-22](https://nextjs.org/blog/upcoming-nextjs-security-release-september-22-2026), [Next.js 16 security patches 2026](https://www.pkgpulse.com/guides/nextjs-16-security-patches-cve-2026), [16.2.6 / 15.5.18 advisories (13)](https://lilting.ch/en/articles/nextjs-security-release-16-2-6-15-5-18), [August 2026 critical RCE write-up](https://teramont.net/blog/nextjs-16-3-3-15-5-24-critical-rce).
- Search results describe an August 2026 release (safe version `16.3.3` on the active line) fixing two critical issues that can lead to RCE. The repo is below that. This comes from third-party write-ups, so confirm against the official advisory.
- Earlier 2026 issues fixed before `16.1.7` include a Server Action CSRF bypass (`origin: null` treated as missing) and unbounded `next-resume` bodies in PPR, a DoS vector.
- Any bump needs a stated reason and human approval under `AGENTS.md`. After it, run `npm test && npm run lint && npm run build`.

### P0 — Starlette floor (*carried from 10-06*)
`starlette>=0.49.1` has no ceiling, and the resolved version in the running image is unverified. Starlette `1.7.0` is the latest. Check with `pip show starlette` in the backend container, then set an explicit floor.

### P1 — Redis `7.4.9-alpine`
Sources: [Redis advisory, 2026-05-05](https://threatcluster.io/cluster/redis-security-advisory-addresses-multiple-vulnerabilities-7494cf21).
Five CVEs (CVE-2026-23479, -25243, -25588, -25589, -23631) allow RCE after authenticated access. Which tag fixes them on the 7.4 line was not determined. Redis is probably only reachable on the internal Docker network. Confirm that, and check whether a password is set.

### P1 — PostgreSQL `16-alpine`
Sources: [PostgreSQL advisory, 2026-05-14](https://cyber.gc.ca/en/alerts-advisories/postgresql-security-advisory-av26-470), [Feb 2026 advisory](https://cyber.gc.ca/en/alerts-advisories/postgresql-security-advisory-av26-125).
The May release fixed 11 vulnerabilities across versions 14–18. The floating `16-alpine` tag picks up minors on pull, but only if the image is re-pulled. Confirm the deployed minor with `SELECT version();`.

### P2 — Dependency drift
FastAPI, SQLModel, Alembic, redis-py and RQ are all behind. Bump in small, separately tested slices. The `redis` 7→8 and `rq` 2.7→2.12 changes touch the backtest queue and need a human check of release notes first.
