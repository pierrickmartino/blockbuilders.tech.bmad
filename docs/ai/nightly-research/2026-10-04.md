## Security Risks

### P0 — Next.js `16.2.6` is behind multiple security releases
Sources: [Next.js 16.3.6 out-of-band notice](https://nextjs.org/blog/upcoming-nextjs-security-release-september-22-2026), [Releases · vercel/next.js](https://github.com/vercel/next.js/releases), [Next.js on endoflife.date](https://endoflife.date/nextjs).
- `16.3.6` (09-22): critical issue in an upstream dependency (GHSA-vcvr-r3jv-pc5j). Per the 10-02 report this includes the `next/og` `ImageResponse` RCE; the repo uses `next/og` in the public share route `frontend/src/app/share/backtests/[token]/opengraph-image.tsx`. I did not re-verify that mapping this cycle.
- `16.3.8` (09-30): one High, five Medium, one Low, including SSRF in Image Optimization and App Router metadata image route information disclosure.
- Image Optimization SSRF applicability: a grep of `frontend/next.config.*` for `images` / `remotePatterns` found no match, which suggests remote image optimization is not configured. I did not read the config in full, so this is indicative, not confirmed.
- Per the 10-02 report, a critical and a high issue were deferred to a later release; I found no announcement of that release this cycle.
- Bump needs a dependency-change justification per `AGENTS.md`; run `npm test && npm run lint && npm run build`.

### P0 — Starlette unbounded floor (carried)
`backend/requirements.txt` still has `starlette>=0.49.1`. A fresh resolve should pick a patched version (per 10-02 report, BadHost auth bypass CVE-2026-48710 fixed in 1.0.1), but the deployed container's version is unverified. ### P1 — Redis image `redis:7.4.9-alpine`
Sources: [Redis security advisory (CVE-2026-23479, -25243, -25588, -25589, -23631)](https://redis.io/blog/security-advisory-cve202623479-cve202625243-cve-2026-25588-cve202625589-cve-2026-23631/), [Stingrai writeup](https://www.stingrai.io/blog/redis-rce-2026-cves-ai-27-minute-discovery).
Five CVEs disclosed 2026-05-05, with a further security release set on 2026-07-23. CVE-2026-25589 (RESTORE with RedisBloom, CVSS 7.7) needs an authenticated attacker and a module the repo likely doesn't load. Per-CVE fixed versions on the 7.4 line were not mapped; confirm in Redis release notes before choosing a tag. Both compose files (`docker-compose.yml:98`, `docker-compose.prod.yml:97`) carry the pin.

### P1 — PostgreSQL image currency
