## Security Risks

### P0 — Next.js `16.2.6` behind security releases (carried)
Sources: [Next.js 16.2.6 / 15.5.18 advisories](https://lilting.ch/en/articles/nextjs-security-release-16-2-6-15-5-18), [DEV: July 2026 release](https://dev.to/mr_manushukla/nextjs-july-2026-security-release-9-cves-patched-in-16211-and-15521-3o9b), [achromatic changelog](https://www.achromatic.dev/changelog/july-2026-nextjs-security-release), [pkgpulse](https://www.pkgpulse.com/guides/nextjs-16-security-patches-cve-2026).
- July 2026: nine CVEs (four high, five medium) fixed in `16.2.11`.
- One undated source says `16.3.3` / `15.5.24` fixes two critical RCEs (Windows servers, AVIF optimization). Unverified; confirm on nextjs.org and the GitHub advisories before acting.
- Bump needs a stated reason and human approval. Verify with `cd frontend && npm test && npm run lint && npm run build`.

### P0 — Starlette floor (carried, not re-searched)
- CVE-2026-48710 (Host header handling). `requirements.txt` floor is `>=0.49.1`; the installed version depends on build-time resolution. Check with `pip show starlette` in the backend container. Auth-adjacent: human approval required.

### P1 — Redis server image (carried)
Sources: [Canadian Cyber Centre AV26-859](https://cyber.gc.ca/en/alerts-advisories/redis-security-advisory-av26-859), [Threatcluster summary](https://threatcluster.io/cluster/redis-security-advisory-addresses-multiple-vulnerabilities-7494cf21).
- AV26-859 is dated 2026-08-28. The versions it lists as fixed (8.2.9, 8.4.6, 8.6.6, 8.8.2, 8.10.1) are the 8.x lines; the 7.4.11 mapping comes from the earlier report and was not re-confirmed this cycle.
- May 2026 advisory: five CVEs allowing RCE for an authenticated attacker (CVE-2026-23479, -25243, -25588, -25589, -23631). Self-managed instances must upgrade.
- Action: bump to `7.4.11` or later after confirming the tag exists; check whether Redis TLS is enabled and whether Redis requires auth and is not publicly exposed.

### P1 — PostgreSQL image currency
Sources: [Born City: 11 fixes](https://borncity.com/news/postgresql-schliesst-11-sicherheitsluecken-in-einem-grossen-update/), [AhnLab: CVE-2026-6476](https://asec.ahnlab.com/en/93764/).
- May 2026 release (18.4, 17.10, 16.14, 15.18, 14.23) fixes 11 CVEs, including CVE-2026-6472 (missing authorization in CREATE TYPE), CVE-2026-6476 (SQL injection in `pg_createsubscriber`) and CVE-2026-6478 (MD5 auth timing side channel).
- `postgres:16-alpine` floats. Run `SELECT version();` after a pull and recreate; running version not checked.

### P1 — React Server Components DoS (covered by pin)
Sources: [Corgea: CVE-2026-23870](https://corgea.com/advisories/vulnerabilities/CVE-2026-23870), [Mend: CVE-2026-23869](https://mend.io/vulnerability-database/CVE-2026-23869/).
- CVE-2026-23869 fixed in 19.2.5; CVE-2026-23870 affects 19.2.0–19.2.5 with the fix in 19.2.6 per Corgea (not verified against react.dev). The `19.2.6` pin covers both. Only relevant where Server Functions are used.
