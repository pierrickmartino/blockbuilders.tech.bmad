## Security Risks

### P0 — Next.js `16.2.6` behind security releases
Sources: [Next.js security update notice (09-22)](https://nextjs.org/blog/upcoming-nextjs-security-release-september-22-2026), [Netlify summary, Sept 2026](https://www.netlify.com/changelog/2026-09-30-nextjs-react-security-vulnerabilities/), [Empirical Security, CVE-2026-75604](https://research.empiricalsecurity.com/research/october-2026-cve-of-the-month).
- Fixed in `16.3.8` (09-30): SSRF in Image Optimization, App Router metadata image route info disclosure via `dynamicParams` bypass, SSG/ISR cache poisoning, nested `use cache` leak, dev-server MCP endpoint disclosure.
- The 10-04 report noted that `next.config.*` appeared to have no `images`/`remotePatterns` configuration, which would limit SSRF reachability. That was not confirmed by a full read and I did not re-check it this cycle.
- Per `AGENTS.md`, a dependency bump needs a stated justification and human approval. Run `npm test && npm run lint && npm run build` after.

### P0 — Starlette unbounded floor (*carried*)
`backend/requirements.txt` has `starlette>=0.49.1`. The deployed version is unverified. Recommend a higher floor per the earlier advisory research and a `pip show starlette` in the running container.

### P1 — Redis image
Sources: [Redis security advisory](https://redis.io/blog/security-advisory-cve202623479-cve202625243-cve-2026-25588-cve202625589-cve-2026-23631/), [Stingrai writeup](https://www.stingrai.io/blog/redis-rce-2026-cves-ai-27-minute-discovery).
CVE-2026-23479 (use-after-free in the unblock-client flow, CVSS 7.7, possible RCE) and CVE-2026-25243 (RESTORE, authenticated, CVSS 7.7) are among five disclosed. Fixed versions for the repo's `redis:7.4.9-alpine` line were not mapped; check Redis release notes before choosing a tag. Exposure depends on whether Redis is reachable only from the internal Docker network.

### P1 — PostgreSQL image currency
Sources: [SecurityWeek](https://www.securityweek.com/12-year-old-postgresql-vulnerability-enables-database-server-takeover/), [SentinelOne CVE-2026-2006](https://www.sentinelone.com/vulnerability-database/cve-2026-2006/).
Several 2026 CVEs, including a buffer overflow allowing code execution by authenticated database users and a pg_dump issue. `postgres:16-alpine` floats on the minor, so pull and recreate, then confirm with `SELECT version();`. Per-CVE fixed minors were not confirmed.
