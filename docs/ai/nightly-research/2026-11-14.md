## Executive Summary

1. **Next.js remains the top risk.** The pin `16.2.6` predates the 2026-11-03 security release (one high and six medium advisories, fixed in 16.4.5) and the earlier October, August and September releases. A grep of `frontend/src` and `next.config.*` for `use cache`, Edge runtime and `next/image` returned no matches, so exposure to the headline issues may be low. That grep is a rough check and does not cover config files outside those paths. An upgrade still needs human approval.
2. **New PostgreSQL minor release landed on 2026-11-12** (16.16 for our major). Because `postgres:16-alpine` floats, a fresh pull picks it up. The running patch level on deployed hosts is unknown. The notice also mentions GIN index corruption fixes.
3. **SQLModel is now 11 patch versions behind** (`0.0.38` vs `0.0.49`). The earlier UTC datetime change in 0.0.45 still needs a plan before any bump.
4. **Open issues are unchanged.** Three `ready-for-agent` issues (#618, #570, #555) are still blocked on human PostHog setup (#620, #573, #561).
5. **UX research:** competitor builders (ClashX, Raven, MachineTrader, Composer) use the same patterns we already have: node canvas, entry/exit/filter categories, generate-then-refine. Nothing argues for a change.
