## Executive Summary

1. **Next.js remains the top risk and is still unpatched.** `16.2.6` is behind the official 2026-10-14 out-of-band release (`16.4.1` / `15.5.28`). GitHub now lists four `next` advisories (published 2026-10-22), including a new Moderate one (cache leak across root params in nested `use cache`). Patching needs human approval.
2. **FastAPI moved a long way.** Latest is `0.162.0` versus the `0.136.1` pin. Two recent releases are breaking for form and parameter models. No security fixes appeared in the visible release notes (only about three days of releases were visible).
3. **PostgreSQL:** secondary sources report an 11-CVE release on 2026-05-14 (18.4 / 17.10 / 16.14 / 15.18 / 14.23) and a September SUSE advisory with more CVEs. Dates and severities are inconsistent across sources, so check the official PostgreSQL security page. The compose image uses a floating `16-alpine` tag, so a pull or rebuild should pick up fixes.
4. **Node.js runtime:** one secondary source reports Node.js security releases on 2026-10-21 (22.23.4, 24.22.1, 26.12.1). Single source, *unverified*. A Next.js upgrade does not patch the runtime.
5. **Open issues unchanged.** No open issue is unblocked by upstream changes.
