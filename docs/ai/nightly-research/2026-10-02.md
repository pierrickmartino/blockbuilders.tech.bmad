## Security Risks

### P0 — Next.js pinned at 16.2.6, behind four security releases
Sources: [Next.js security release notice](https://nextjs.org/blog/upcoming-nextjs-security-release-september-2026), [Netlify advisory summary](https://www.netlify.com/changelog/2026-09-30-nextjs-react-security-vulnerabilities/), [Next.js security tag](https://nextjs.org/blog/tag/security).
- 09-30 release (`16.3.8` / `15.5.27`): high SSRF in Image Optimization (private-IP requests via attacker-controlled remote URL); Pages Router SSG/ISR cache poisoning; App Router metadata image-route info disclosure (webpack builds only); low-severity dev-server MCP endpoint data exposure.
- 09-22 out-of-band (`16.3.6` / `15.5.26`): `next/og` `ImageResponse` RCE (CVE-2026-94545), already identified last cycle. The repo imports `next/og` in `frontend/src/app/share/backtests/[token]/opengraph-image.tsx` (public, unauthenticated route).
- `16.3.7` (09-29) was a bug-fix release only and carries **no** security fixes.
- **Still outstanding upstream:** one critical and one high vulnerability, deferred to a later release. Expect another bump soon.
- Applicability to this repo: Image Optimization SSRF applies only if `images.remotePatterns` / remote image URLs are configured; I did not audit `next.config`. A bump is a version change with no expected code changes, but per `AGENTS.md` it needs a dependency-change justification and the full frontend test/lint/build run.

### P0 — Starlette unbounded floor (carried forward)

### P1 — Redis server image behind
`docker-compose.prod.yml:97` pins `redis:7.4.9-alpine`. Current-year Redis advisories ([Redis advisory](https://redis.io/blog/security-advisory-cve202623479-cve202625243-cve-2026-25588-cve202625589-cve-2026-23631/)) cover RESTORE use-after-free / invalid memory access and a Lua use-after-free, all RCE-class and requiring an authenticated client. Prior cycle established `7.4.11-alpine` as the target tag. I did not map each CVE to a specific 7.4.x fixed version this cycle; confirm against the Redis release notes before bumping. The compose network is internal, which lowers but does not remove exposure.
