## Security Risks

### P0 — Next.js `16.2.6` behind the 2026-10-14 update
Sources: [Next.js security update, Oct 14 2026 (official)](https://nextjs.org/blog/nextjs-security-update-october-14-2026), [Singapore CSA AL-2026-148](https://www.csa.gov.sg/alerts-and-advisories/alerts/al-2026-148/).

| Advisory | Severity | Condition | Repo status |
|---|---|---|---|
| GHSA-673q-mjm6-r5xr (+ React GHSA-xqc2-xf4c-x3h3) | Critical | App Router + Cache Components, `use cache` returning typed arrays; no workaround | no `use cache` found |
| CVE-2026-96889 / GHSA-2464-fhr4-w9xw | Critical | Image Optimization API (SVG) on glibc Linux; workaround `sharp` >= 0.35.5 | musl image, no `next/image` use |
| GHSA-p3m5-59mp-jv5r (+ React GHSA-h3gv-c5rc-p453) | High | App Router with at least one Server Action; CPU DoS | no `"use server"` found |

- Recommendation: human-approved bump to `next@16.4.1` (or newer 16.x patch), `react`/`react-dom` aligned. It crosses 16.2 to 16.4: read the 16.3/16.4 notes, then run `cd frontend && npm test && npm run lint && npm run build`.
- Caveat: greps cover app code only; conditions are about the app's own code, so low likelihood elsewhere.
