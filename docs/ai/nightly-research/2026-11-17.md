## Executive Summary

1. **Next.js security release, now confirmed from the primary source.** The official post (2026-11-03) lists 7 advisories (1 High, 6 Medium), fixed in `16.4.5` and `15.5.29`. Last night's report could not reproduce this. Our pin `16.2.6` predates it.
2. **Our exposure looks low, but is not proven.** A grep of `frontend/` found no `use cache`, `unstable_cache`, `cacheComponents`, Edge runtime or `next/image` usage. Five of the seven advisories need Cache Components or Edge routes; one needs `next/image`. The self-hosted advisory (stale compressed response framing) needs an HTTP/1.1 proxy that pipelines requests and an attacker-controlled fetched `Response` returned unchanged. We run `output: "standalone"`, so that last item needs checking. Still, the pin is behind and a bump should be planned.
3. **Open issues unchanged.** `ready-for-agent`: #618, #570, #555. Each is blocked on a `ready-for-human` PostHog setup issue (#620, #573, #561).
4. **FastAPI is at least six minors behind** (`0.136.1` vs `0.142.2` per a stale feed). No advisory found.
5. **Visual-builder UX research confirms the current design direction.** No change recommended.
