### P1, unchanged — Redis: `redis:7.4.9-alpine` (repo's exact pinned tag) still has the unpatched authenticated-RCE-class bug; fix is still `7.4.10`

That remains the correct fix for the Streams `RESTORE`-payload shared-NACK use-after-free plus the RedisBloom/TDigest out-of-bounds write. **No CVE/CVSS assigned yet** to this specific bug pair as of today.
**Correction for the record:** `CVE-2026-25589` is a *different*, already-fixed RedisBloom out-of-bounds issue disclosed 2026-05-05 via Redis's own advisory and already patched in `7.4.9` — some third-party writeups conflate it with the new shared-NACK bug. When this fix eventually ships with a real CVE ID, verify it's a genuinely new identifier before citing it.

### P1, unchanged (5th consecutive cycle) — Next.js: 9 CVEs (4 HIGH, 5 MODERATE), fixed in 16.2.11+; repo still on vulnerable 16.2.6; gap widened today
**Next.js 16.3.0 stable shipped today, 2026-08-03** (`nextjs.org/blog/next-16-3`) — Instant Navigations, Turbopack memory/build improvements, TypeScript 7 support, and a vendored-lodash bump (4.17.23) fixing an unrelated `CVE-2025-13465`. This is a feature release, not a new security bulletin for Next.js itself — GitHub Security Advisories for `vercel/next.js` show no new entries since 2026-07-21. The 9 CVEs below are unchanged and still apply in full to the repo's pinned `16.2.6`:

| Severity | CVE | Summary |
|---|---|---|
| HIGH | CVE-2026-64641 | DoS in App Router using Server Actions |
| HIGH | CVE-2026-64642 | Middleware/Proxy bypass in App Router + Turbopack + single locale |
| HIGH | CVE-2026-64645 | SSRF in rewrites via attacker-controlled destination hostname |
| HIGH | CVE-2026-64649 | SSRF in Server Actions on custom servers |
| MODERATE | CVE-2026-64643 | Unauthenticated disclosure of internal Server Function endpoints |
| MODERATE | CVE-2026-64644 | DoS in Image Optimization API using SVGs |
| MODERATE | CVE-2026-64646 | Unbounded Server Action payload in Edge runtime |

All ranges `>=16.0.0, <16.2.11`; repo's pinned `16.2.6` is inside every one.
