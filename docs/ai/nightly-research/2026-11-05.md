## Implementation References

- **Progressive disclosure for the builder.** Raven, a prediction-market builder, found a raw node canvas overwhelming. It generates a strategy from templates or a wizard, then converts it to a node canvas the user can edit. This matches our wizard-to-canvas flow (product §4.4) and is relevant to #618. Source: [DEV Community](https://dev.to/emilanielsen/building-a-no-code-trading-bot-builder-for-prediction-markets-raven-26fp). This is a vendor blog.
- **Type checking between blocks.** Composer's blocks each do one operation, and the editor stops a ticker list from feeding a numeric input. This supports #510, where a shared validator could drive connection-time port checks. Source: [DEV Community](https://dev.to/pickuma/composer-review-automated-trading-strategies-without-writing-code-lj3).
- **Sentence-style conditions with AND/OR groups** (EA-Builder, [mql5](https://www.mql5.com/en/blog/post/772799)). Our deterministic explanation generator (product §4.8) already goes in that direction. The mql5 URL above is from the search results as `/en/blogs/post/772799`, so use that form when checking it.
- **Drag threshold on click-select** (Handoff interface), to avoid accidental node moves. React Flow supports this through its `nodeDragThreshold` prop. I did not verify this against the docs tonight, so confirm before relying on it.
