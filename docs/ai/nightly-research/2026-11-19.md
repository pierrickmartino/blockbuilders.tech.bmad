## Executive Summary

1. **The React Server Components RCE flagged as unverified last night is real.** The GitHub advisory GHSA-xqc2-xf4c-x3h3 (CVE-2026-126187) is **Critical, CVSS v4 9.5**, "Unauthenticated Remote Code Execution in React Server Components" (CWE-502, deserialization). It was published 2026-10-14 and added to the GitHub Advisory Database on 2026-11-10. Affected packages are `react-server-dom-webpack`, `-parcel` and `-turbopack`, versions 19.0.0–19.0.8, 19.1.0–19.1.9, 19.2.0–19.2.8 and 19.3.0. Patched in 19.0.9, 19.1.10, 19.2.9 and 19.3.1. The advisory says it only triggers in rare cases where responses carry multiple typed arrays plus an attacker-controlled value.
2. **Exposure for us is not yet determined.** Our `react` pin is `19.2.6`, which is in the affected range. The vulnerable code lives in the `react-server-dom-*` packages, not in `react` itself. Next.js App Router bundles its own copy of the server renderer. So the real fix is probably a Next.js upgrade, not a `react` bump alone. I did not confirm which Next.js version carries the patched copy. A human or the next agent run should check `npm ls react-server-dom-webpack react-server-dom-turbopack` and the Next.js 16.4.5 release notes.
3. **Next.js `16.2.6` is behind the patched `16.4.5`.** Third-party sources report 7 advisories on 2026-11-03, including a cross-tenant cache leak (GHSA-mfr8-8qww-v76h, Moderate 6.3, said to affect 16.3.0–16.4.4, which would not include our 16.2.6). Severity and count differ between sources. Treat as *unverified* until read on GitHub.
4. **FastAPI is far behind:** `0.136.1` vs `0.165.0`, with three releases in the last two days (0.163.1, 0.164.0, 0.165.0). The 0.162.6 release (2026-11-13) has a "Breaking Changes" heading. I could not read its body (page truncated at 100k of 442k characters). Read it before any bump.
5. **Open issues unchanged.** `ready-for-agent`: #618, #570, #555, each blocked on a `ready-for-human` PostHog task (#620, #573, #561). Nothing is agent-actionable. The `ai-ready` label does not exist; `ready-for-agent` is the equivalent.
