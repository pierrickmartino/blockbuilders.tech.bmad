## Executive summary

- **Next.js:** the official November 3 security release (16.4.5 / 15.5.29) has 7 advisories (1 High, 6 Medium). We pin `next 16.2.6`. A repo grep found no use of `use cache`, `unstable_cache`, `cacheComponents`, Edge routes or `dangerouslyAllowSVG` in `frontend/`, so the cache and Edge advisories look unexploitable today. The upgrade is still due, since 16.2.6 is two minors behind the Active LTS line.
- **Starlette:** CVE-2026-48710 ("BadHost", Host-header validation bypass) was reported as added to CISA KEV on 2026-09-02, with the fix in Starlette 1.0.1. `backend/requirements.txt` only floors `starlette>=0.49.1`, so the installed version depends on the resolver. This is the highest-priority action and needs verification.
- **PostgreSQL:** the compose files use the floating tag `postgres:16-alpine`. Search results show security releases in May and August 2026 (PG 16.15 is reported for August). No November release was found.
- **Redis:** `redis:7.4.9-alpine` matches the fixed 7.4.9 listed for the May 2026 advisory. A later advisory (CVE-2026-81934, reported 2026-08-28) is not yet checked against it.
- **Toolchain drift:** TypeScript 7.0 (Go-native compiler) is reported GA as of 2026-07-08, and we are on 5.9.3. Tailwind is on 3.4.19, while v4.3.x is current. `@xyflow/react` is `^12.10.0`, and 12.12.0 is the latest reported. FastAPI is on 0.136.1, and the newest reported is 0.142.x.
- **Open issues:** no issue carries an `ai-ready` label (the label still doesn't exist; see Questions). Open issues are listed below.
