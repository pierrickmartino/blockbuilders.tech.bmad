## Security Risks

### P0 — Next.js `16.2.6` behind security releases
Sources: [Next.js 16.2.6 / 15.5.18 advisories](https://lilting.ch/en/articles/nextjs-security-release-16-2-6-15-5-18), [DEV: July 2026 release](https://dev.to/mr_manushukla/nextjs-july-2026-security-release-9-cves-patched-in-16211-and-15521-3o9b), [achromatic changelog](https://www.achromatic.dev/changelog/july-2026-nextjs-security-release), [pkgpulse](https://www.pkgpulse.com/guides/nextjs-16-security-patches-cve-2026).
- July 2026: nine CVEs (four high, five medium) fixed in `16.2.11`, including SSRF, middleware/proxy bypass and DoS.
- One undated secondary source says `16.3.3` fixes two critical RCEs involving Windows servers and AVIF optimization. Unverified; confirm on nextjs.org and the GitHub advisories before acting.
- Dependency bump needs a stated reason and human approval. Verify with `cd frontend && npm test && npm run lint && npm run build`.

### P0 — Starlette floor too low (*carried, not re-searched*)
- CVE-2026-48710 (Host header handling affecting `request.url`), fixed in Starlette `1.0.1` per earlier reports. `requirements.txt` has `starlette>=0.49.1`, so the installed version depends on build-time resolution. Check with `pip show starlette` in the backend container.
- Touches the auth surface: human approval required.

### P1 — Redis server image behind patched tag (new)
Sources: [Redis advisory CVE-2026-81934](https://redis.io/blog/security-advisory-cve-2026-81934.md), [Canadian Cyber Centre AV26-859](https://cyber.gc.ca/en/alerts-advisories/redis-security-advisory-av26-859), [Vulert: Red Hat Redis 7](https://vulert.com/vuln-db/red-hat-security-advisory-redis-7-security-update--4).
- Fixed OSS releases: 8.10.1, 8.8.2, 8.6.6, 8.4.6, 8.2.9, **7.4.11**, 7.2.16, 6.2.24. Redis rates it High (CVSS v4 7.5); the initial CVE record said 9.8 and Redis asked for review. No known active exploitation as of 2026-08-27.
- Compose uses `redis:7.4.9-alpine`. Action: bump to `7.4.11` or later 7.4.x after confirming the tag exists and checking whether Redis TLS is enabled.
- Also from May 2026 (secondary summary): five authenticated-RCE-class CVEs (CVE-2026-23479, -25243, -25588, -25589, -23631). Fixed-tag mapping for 7.4.x not confirmed.

### P1 — PostgreSQL image currency
Sources: [Clever Cloud: 18.4 update](https://www.clever.cloud/developers/changelog/2026/05-21-pg-update-18.4/), [Releasebot PostgreSQL feed](https://releasebot.io/updates/postgresql/postgresql).
- May 14 2026 release (18.4, 17.10, 16.14, 15.18, 14.23) fixes 11 CVEs, including CVE-2026-6473 (integer wraparound, CVSS 8.8), CVE-2026-6472 (search_path hijack via CREATE TYPE), CVE-2026-6479 (SSL/GSS recursion DoS) and CVE-2026-6638 (logical replication SQL injection; 16/17/18).
- `postgres:16-alpine` floats; run `SELECT version();` after pull and recreate to confirm 16.14 or later. Running version not checked.
- Debian tracker entries for later CVE IDs list postgresql-17/18 as unfixed; I could not tie them to a release. Check the official PostgreSQL security page.
