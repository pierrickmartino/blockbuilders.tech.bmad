### NEW — TrapDoor: cross-ecosystem campaign that poisons AI-assistant config files (`CLAUDE.md`, `.cursorrules`)
First identified 2026-05-19 (pre-dates this window but new to this report's corpus), 34 malicious packages / 384+ versions across npm, PyPI, and Crates.io, targeting crypto/DeFi/Solana/AI developer environments with decoy "security scanner" and "toolkit" packages (e.g. `prompt-engineering-toolkit`, `eth-security-auditor`, `defi-risk-scanner`, `sui-move-build-helper` — none of which match this repo's dependency list). Its distinguishing technique: the payload plants `.cursorrules` and `CLAUDE.md` files containing **zero-width-Unicode-obscured hidden instructions** disguised as an "automated security scan" prompt, designed to make an AI coding assistant exfiltrate credentials on the developer's behalf. The threat actor has also submitted deceptive pull requests containing poisoned config files to prominent open-source AI projects (LangChain, MetaGPT, OpenHands) via a GitHub account (`ddjidd564`).
**This repo is a plausible target class** — it drives Claude Code, Codex, and Jules via `CLAUDE.md`, `AGENTS.md`, and `.claude/skills/*.md` as first-class, automatically-loaded instructions (per this repo's own `AGENTS.md` "Skill systems" section). **Defensive check performed this cycle (read-only):** scanned `CLAUDE.md`, `AGENTS.md`, and every file under `.claude/` for zero-width space/joiner characters (U+200B–U+200F, U+2060–U+2064), bidirectional-control characters (U+202A–U+202E), and BOM/ZWNBSP (U+FEFF). **Result: clean, no hidden or invisible Unicode characters found.**
**Action (new recommendation):** add a periodic (e.g. CI or pre-merge) check for invisible/zero-width Unicode in `CLAUDE.md`, `AGENTS.md`, and `.claude/**/*.md`, and apply extra scrutiny to any PR that modifies these files, especially from unfamiliar contributors — this is the specific delivery vector TrapDoor uses.
