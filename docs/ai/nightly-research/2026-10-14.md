## Security Risks

### P0 — Next.js `16.2.6` behind security releases
Sources: [DEV: July 2026 release](https://dev.to/mr_manushukla/nextjs-july-2026-security-release-9-cves-patched-in-16211-and-15521-3o9b), [ecorpit: July release](https://ecorpit.com/nextjs-july-2026-security-release-cve-upgrade-2026/), [teramont: 16.3.3 critical RCE](https://teramont.net/blog/nextjs-16-3-3-15-5-24-critical-rce), [pkgpulse](https://www.pkgpulse.com/guides/nextjs-16-security-patches-cve-2026).
- July 2026: nine CVEs (four high, five medium) fixed in `16.2.11`: Server Actions DoS, a Turbopack single-locale middleware/proxy bypass, SSRF.
- August 2026: two critical RCE issues reported fixed in `16.3.3`, flagged as urgent for Windows servers and AVIF image optimization. Single secondary source; confirm on [nextjs.org/blog](https://nextjs.org/blog) and the GitHub advisories before acting.
- Exposure of the Linux Docker deployment is not assessed.
- A bump needs a stated justification and human approval. Verify with `cd frontend && npm test && npm run lint && npm run build`.

### P0 — Starlette floor too low (*carried, not re-searched*)
- CVE-2026-48710 ("BadHost"): unvalidated `Host` header affects `request.url`; fixed in `1.0.1`. Per the 10-13 report, `request.url.path` is read at `backend/app/main.py:71` and `:83`; auth, CORS and rate-limit use were not checked.
- `requirements.txt` pins `fastapi==0.136.1` with `starlette>=0.49.1`, so the installed version depends on build-time resolution. Run `pip show starlette` in the container.
- Touches the auth surface: human approval required.

### P1 — React Server Components DoS (covered by current pin)
Sources: [GitLab: CVE-2026-23870](https://advisories.gitlab.com/npm/react-server-dom-turbopack/CVE-2026-23870/), [GitLab: CVE-2026-23869](https://advisories.gitlab.com/npm/react-server-dom-parcel/CVE-2026-23869/), [GitLab: CVE-2026-23864 mirror via AhnLab](https://asec.ahnlab.com/en/92377/).

- CVE-2026-23869 (April) is fixed in `19.2.5`; CVE-2026-23864 (January) in `19.2.4`. Both are covered by `19.2.6`.
- Earlier CVE-2025-55182 (critical RCE, CVSS 10.0) is fixed since `19.2.1`.
- Only third-party mirrors were seen for the 2026 CVEs; no official react.dev post.
