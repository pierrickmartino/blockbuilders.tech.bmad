## Security Risks

Priority order. Items marked *(carried)* come from the 09-26 report and were not re-verified this cycle.

- **P0: Next.js.**
  - The 2026-09-22 out-of-band release `16.3.6` fixes a critical RCE (GHSA-vcvr-r3jv-pc5j) in the Node.js `ImageResponse` (`next/og`), caused by improper SVG escaping in Satori. It affects `>=16.2.0 <16.3.6` ([Next.js](https://nextjs.org/blog/upcoming-nextjs-security-release-september-22-2026)).
  - *(carried)* The repo uses `next/og` in `frontend/src/app/share/backtests/[token]/opengraph-image.tsx`, a public unauthenticated route. Its interpolated fields are constrained to enums and numbers, which lowers practical exploitability but does not remove it.
  - Two earlier critical/high RCEs fixed in `16.3.3` are also unpatched at `16.2.6` *(carried)*.
  - `16.3.7` lands 2026-09-30. Upgrade directly to it. This is a version bump only, but it touches a framework dependency, so it needs a spec and human approval per AGENTS.md.
- **P0: Starlette "BadHost" (CVE-2026-48710).** *(carried)* Fixed in `1.0.1`, and reported as actively exploited with a public PoC. The repo has only `starlette>=0.49.1`. A fresh install resolves to `1.7.0`, so a clean build is not exposed. The deployed container has never been confirmed. Action: run `pip show starlette` inside the running backend container, and add an explicit `starlette>=1.0.1` floor.
- **P1: Redis image.** *(carried)* `redis:7.4.9-alpine` is behind `7.4.11-alpine`. The fixes bundled between them include a UAF-to-RCE via stream `RESTORE`, an ACL bypass, and memory corruption during RDB load. The repo uses plain `redis://`, so the TLS fix is not relevant. Action: bump the tag in both compose files.
- **P1: PostgreSQL minors.** See the Executive Summary. The repo uses a floating tag, so the risk is a stale deployed image rather than a stale pin.
- **Background:** React 19.2.x has had several RSC advisories over the past year. The May 2026 joint Next.js/React release patched 12 vulnerabilities ([Netlify summary](https://www.netlify.com/changelog/2026-05-08-react-nextjs-security-vulnerabilities/)). React `19.2.8` (2026-07-21) exists on the 19.2 line, and the repo is on `19.2.6`. Check whether a 19.2.x patch bump is covered by the Next.js upgrade.
