## Security Risks

### P0 — Next.js `16.2.6` behind security releases (carried)
Sources: [Next.js blog](https://nextjs.org/blog), [releases.sh digest, 2026-08-24](https://releases.sh/collections/frontend-frameworks/digest/2026-08-24.md).
- A Vercel post dated 2026-07-20 urges moving to `16.2.11` (Active LTS) or `15.5.21`.
- The August digest reports `16.3.3` and `15.5.24` patching unauthenticated RCEs affecting Windows-hosted servers and the Image Optimization API's AVIF handling. The search tool could not confirm this against a primary source. Vercel says it will publish security patches on a more regular cadence.
- Whether the repo uses middleware auth, i18n, or `next/image` with AVIF was not checked.
- A bump needs a stated reason and human approval. Verify with `cd frontend && npm test && npm run lint && npm run build`.

### P1 — React Server Components DoS advisories
Sources: [Corgea CVE-2026-23870](https://corgea.com/advisories/vulnerabilities/CVE-2026-23870), [Endor Labs](https://www.endorlabs.com/learn/critical-remote-code-execution-rce-vulnerabilities-in-react-and-next-js).
- CVE-2026-23870 (RSC server-function endpoint DoS) affects 19.2.0–19.2.5; fixed in `19.2.6`. The repo pins `19.2.6`, so it should be covered. CVE-2026-23869 is reported as High by a secondary blog; verify against the GitHub advisory.
- CVE-2025-55182 (Dec 2025, CVSS 10.0 RCE in Flight deserialization) was fixed long before these versions. It matters because Next.js bundles its own React Server Components code, so the Next.js version is the real control.

### P1 — PostgreSQL May 2026 security release (carried, re-seen)
Source: [AhnLab advisory](https://asec.ahnlab.com/en/95301/).
- 18.4, 17.10, 16.14, 15.18, 14.23 (2026-05-14) fix 11 CVEs, including CVE-2026-6472 (CREATE TYPE permission check) and CVE-2026-6478 (MD5 auth timing side channel).
- `postgres:16-alpine` floats, so a fresh pull should be 16.14 or later. Confirm with `docker compose exec db postgres --version`.
- A Vulert listing for CVE-2026-6479 carries an ambiguous 10/08/2026 date; treat as unconfirmed.

### P1 — Redis server image
Source: [Canadian Centre for Cyber Security, AV26-423](https://cyber.gc.ca/en/alerts-advisories/redis-security-advisory-av26-423).
- May 2026 advisory lists five CVEs (CVE-2026-23479, -25243, -25588, -25589, -23631) with RCE potential for authenticated users. Self-managed servers must upgrade. Whether `7.4.9` is affected was not confirmed; check the fixed 7.4.x tag and make sure Redis is not publicly exposed and requires auth.
- Two further CVEs (CVE-2026-66373, CVE-2026-81934, CVSS 7.5) appear on an undated Vulert page; unconfirmed.

### P0 — Starlette floor (carried, not re-searched)
- CVE-2026-48710 (Host header handling). `requirements.txt` floor is `>=0.49.1`; installed version depends on build-time resolution. Check `pip show starlette` in the backend container. Auth-adjacent: human approval required.
