## Implementation References

- **Next.js upgrade:** `npm install next@16.4.5` per the release post. Upgrading across two minors should be followed by `npm test && npm run lint && npm run build`. Review the 16.3 and 16.4 release notes for deprecations before merging. This was not done tonight.
- **React Flow with Tailwind 4 (from the 2026-11-03 report):** React Flow's changelog says its UI components support shadcn/ui on React 19 and Tailwind 4, with the React Flow stylesheet imported after Tailwind. Useful for the future Tailwind migration. [reactflow.dev](https://reactflow.dev/whats-new/2025-10-28)
- **Node-editor UX (practitioner blogs, low rigor):** distinct visual identity per node type, highlighting the executed path, and reusable subflows for repeated patterns. Blockbuilders already has category colors in the minimap (§4.11.2), canvas validation highlighting (§4.9) and copy/paste of subgraphs (§4.10). The only idea not obviously covered is an overlay of which blocks fired on a given trade or candle in backtest results. That is a possible future idea and not a recommendation for now. Source: [Medium](https://medium.com/@npavfan2facts/visual-programming-for-no-code-builders-67c3989182a5)
