## Security Risks

### P0 — Next.js `16.2.6` behind security releases (*carried, partly re-seen*)
Sources: [lilting.ch, 16.2.6/15.5.18 advisory summary](https://lilting.ch/en/articles/nextjs-security-release-16-2-6-15-5-18), [DEV: July 2026 release](https://dev.to/mr_manushukla/nextjs-july-2026-security-release-9-cves-patched-in-16211-and-15521-3o9b), [pkgpulse: Next.js 16 security patches](https://www.pkgpulse.com/guides/nextjs-16-security-patches-cve-2026).
- This cycle's search re-confirmed: `16.2.6` shipped 2026-05-07 with 13 advisories; the July 20 release fixed 9 CVEs in `16.2.11` (including a Turbopack single-locale middleware bypass, CVE-2026-64642); a later item reports two critical RCEs fixed in `16.3.3`.
- The pinned `16.2.6` predates all of these. Details for August/September come from the 10-09 report and were not re-verified; check official advisories.
- A bump needs a stated justification and human approval per `AGENTS.md`. Verify with `cd frontend && npm test && npm run lint && npm run build`.

### P0 — Starlette floor too low (*carried*)
`starlette>=0.49.1` allows versions affected by CVE-2026-48710 (fixed 1.0.1) and CVE-2026-54282 (fixed 1.3.0), both about unvalidated request data used to rebuild `request.url`. Exposure depends on whether auth, CORS or rate-limit code keys off `request.url`; not checked. Touches the auth surface, so human approval is required. Not re-searched this cycle.

### P1 — PostgreSQL image currency
Sources: [AhnLab advisory (CVE-2026-6476)](https://asec.ahnlab.com/en/93764/), [Determinate Systems CVE tracker](https://security.determinate.systems/cves/status/open?page=2), [postgresql.org security page](https://www.postgresql.org/support/security/).
- May 2026 fixes (18.4, 17.10, 16.14, 15.18, 14.23): CVE-2026-6472–6479, 6637, 6476 (`pg_createsubscriber` SQL injection), 6575, 6638, including an MD5 authentication timing side channel.
- Possible next batch (16.15 etc.): unconfirmed, see Executive Summary item 2.
- `postgres:16-alpine` floats on the minor; confirm `SELECT version();` is 16.14 or later after a pull and recreate. The current tag was not checked.

### P1 — Redis image (*carried*)
CVE-2026-23479 and CVE-2026-25243 (CVSS 7.7) per the 10-06 report; fixed versions for `redis:7.4.9-alpine` were never mapped. Exposure depends on Redis being reachable only on the internal Docker network. Not re-searched.

### MONITOR
No advisories surfaced for SQLModel, Alembic or RQ; absence of results is not proof of absence. redis-py 8.x and RQ `>=2.9.1` must be bumped together.
