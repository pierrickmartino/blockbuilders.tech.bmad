## Security Risks

### P0 — Next.js `16.2.6` behind security releases
Sources: [Next.js, upcoming security release 2026-09-22](https://nextjs.org/blog/upcoming-nextjs-security-release-september-22-2026), [Next.js 16.2.6 / 15.5.18 advisory summary](https://lilting.ch/en/articles/nextjs-security-release-16-2-6-15-5-18), [July 2026 release summary](https://dev.to/mr_manushukla/nextjs-july-2026-security-release-9-cves-patched-in-16211-and-15521-3o9b), [Vercel, August 2026 release](https://vercel.com/changelog/nextjs-august-2026-security-release).
- July: nine CVEs fixed in `16.2.11` / `15.5.21` (four high, five medium).
- August 25: two critical RCEs, fixed in `16.3.3` / `15.5.24`.
- September 22: out-of-band critical fix in an upstream dependency (`16.3.6` / `15.5.26`), GHSA-vcvr-r3jv-pc5j.
- September 30: further batch, with `16.3.8` reported as current by a third-party blog. The earlier 10-06 report listed its contents. I could not re-confirm those details this cycle; check the official advisories.
- `16.2.6` predates all of these. The pinned version is therefore exposed to everything above unless a fix was also backported to `16.2.x`; confirm against the advisories.
- Per `AGENTS.md`, a dependency bump needs a stated justification and human approval. Run `cd frontend && npm test && npm run lint && npm run build` afterward.

### P0 — Starlette floor too low
Sources: [CCB Belgium advisory (BadHost)](https://ccb.belgium.be/advisories/warning-vulnerability-starlette-framework-and-related-frameworks-fastapi-exposes), [CVE-2026-48710](https://db.gcve.eu/vuln/CVE-2026-48710), [INCIBE listing (CVE-2026-54282)](https://www.incibe.es/index.php/en/incibe-cert/early-warning/vulnerabilities?page=1131).
- `backend/requirements.txt` has `starlette>=0.49.1`. The deployed version is unverified.
- CVE-2026-48710 (CVSS 6.5): Host header not validated before rebuilding `request.url`; middleware keyed on that URL can be bypassed. Fixed in 1.0.1.
- CVE-2026-54282: request path not validated before rebuilding `request.url`. Fixed in 1.3.0.
- Recommend: run `pip show starlette` in the live container, grep `backend/app` for `request.url` use in auth, CORS or rate-limit code, and raise the floor to `>=1.3.0` if FastAPI's pin allows it. Major-version jump (0.x → 1.x), so test thoroughly. This touches the auth surface, so human approval is required.

### P1 — PostgreSQL image currency
Sources: [Born City summary](https://borncity.com/news/postgresql-schliesst-11-sicherheitsluecken-in-einem-grossen-update/), [AhnLab advisory](https://asec.ahnlab.com/en/93764/).
- May 2026 releases fixed 11 CVEs (including a `pg_createsubscriber` SQL injection, CVE-2026-6476, and an MD5 authentication timing side channel, CVE-2026-6478). Patched minors: 18.4, 17.10, 16.14, 15.18, 14.23.
- `postgres:16-alpine` floats on the minor; pull, recreate, and check `SELECT version();` shows 16.14 or later. The tag's current minor was not checked.

### P1 — Redis image (*carried*)
Per the 10-06 report: CVE-2026-23479 and CVE-2026-25243 (CVSS 7.7, possible RCE) among five disclosed. Fixed versions for the repo's `redis:7.4.9-alpine` line were not mapped. Exposure depends on Redis being reachable only on the internal Docker network. Not re-searched this cycle.
