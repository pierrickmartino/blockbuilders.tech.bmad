## Executive Summary

1. **Bump `next` to at least 16.4.5.** The November security release (2026-11-03) patches seven advisories in 16.4.5 and 15.5.29. Sources disagree on severity (Netlify: Medium; one write-up: 1 High, 6 Medium). It includes a cross-tenant cache leak (16.3.0–16.4.4, CVSS 6.3) and an SVG rejection bypass in the image optimizer. 16.4.5 also covers the two Criticals from October (fixed in 16.4.1). Our `16.2.6` predates all of them. It is a human decision per `AGENTS.md`.
2. **Correction to 2026-11-20: the app does use `next/og`.** `frontend/src/app/share/backtests/[token]/opengraph-image.tsx` imports `ImageResponse` from `next/og`. The earlier report said "no `next/og` usage was checked". The `next/og` RCE (GHSA-vcvr-r3jv-pc5j, 2026-09-22) is therefore potentially relevant to a public, tokenized share route. Its fixed version was not read. It likely falls under the same 16.4.x bump, but confirm.
3. **`sharp` is resolved at 0.34.5 in `package-lock.json`.** The Next advisory write-up asks for `sharp` ≥ 0.35.5. We are below it. No `next/image` usage exists (grep), and the runner is `node:20-alpine` (musl), so exposure through the Image Optimization path looks low. A Next upgrade should refresh it. Verify after the bump.
4. **PostgreSQL batch of 2026-11-12 (52 CVEs).** Fixed in 18.7, 17.12, 16.16, 15.20, 14.25. Headline CVE-2026-6460 (CVSS 8.8, authenticated type confusion). PG 14 is now EOL. Both `docker-compose.yml` and `docker-compose.prod.yml` use the floating `postgres:16-alpine` tag, so prod is only on 16.16 after a pull and recreate. Next scheduled PG security release: 2027-02-11 (search).
5. **PostgreSQL 19 GA was planned for 2026-11-19** (one search result). No GA confirmation was found. This stays unverified. It matters only for #334.
6. **FastAPI is far behind** (`0.136.1` vs `0.163.0` on a mirror). Tonight's search found 0.136.2/0.136.3 changes (SSE field validation, underscore headers no longer accepted when `convert_underscores=True`). The 0.162.6 "Breaking Changes" entry mentioned on 2026-11-18 is still unread.
7. **Open issues are unchanged.** `ready-for-agent` #618, #570, #555 are each blocked on a `ready-for-human` PostHog task (#620, #573, #561). No agent-actionable work.
